# Simulation files

No circuit model created yet. The first model will be based on the confirmed existing wiring.

Keep LTspice source files here. Use a descriptive revision such as `buck-baseline-r01.asc`. In each experiment, record the exact file revision used and any simulation assumptions.

For external models, record the part number, manufacturer URL, download date, model pin order, and any compatibility changes. Save permitted model files locally; otherwise record retrieval instructions. Preserve model notices and terms.

Large generated `.raw` files are excluded from Git by default. Retain selected waveform exports and the settings needed to reproduce them.
